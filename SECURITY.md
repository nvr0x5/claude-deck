# Security policy

Deck runs inside Claude Code with your permissions, like every mod. It only watches events and draws; it never changes a request, blocks a tool call, or sends your prompts or code anywhere. Its only network requests go to Open-Meteo, and only after you set a weather city.

## Reporting a vulnerability

Please report security issues privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue for them.

You'll get a reply as soon as possible, and a fix will ship as a new version you can update to from `/plugin`.
